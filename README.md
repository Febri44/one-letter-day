# one-letter-day

Exactly one letter, standing for the word that describes the day, written to
`/output/entry.txt` by `main.ts` (Node 22). Built for the make.fun bounty
[One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36).

## Run

```sh
node main.ts
```

It writes the letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
